# HTML 沙盒 PWA

貼上 HTML 原始碼，即時預覽並測試的行動工具。

## 功能
- ✏️ 貼上 HTML 原始碼即時預覽（`iframe srcdoc`，iOS 相容）
- 📋 一鍵複製原始碼到剪貼簿
- 🖥️ Tab 切換編輯器 / 預覽
- 📲 PWA：可加入 iOS/Android 主畫面離線使用
- 🖱️ 桌面支援拖曳 `.html` 檔案載入

## 部署到 GitHub Pages

1. 建立新 repo（例如 `html-sandbox`）
2. 上傳 `index.html`
3. Settings → Pages → Branch: `main` / `root`
4. 訪問 `https://<你的帳號>.github.io/html-sandbox/`

## 安裝為 PWA（iOS）

1. 用 Safari 開啟上方網址
2. 點分享按鈕 → 「加入主畫面」
3. 即可像 App 一樣全螢幕使用
